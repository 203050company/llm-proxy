# Suggested commands

- `npm run dev`: run backend in watch mode.
- `npm run dev:web`: run the Vite dashboard dev server.
- `npx tsc --noEmit --pretty false`: fast TypeScript validation without emitting files.
- `npm run test:unit`: run unit tests.
- `npm run test:integration`: run integration tests.
- `npm run test:e2e`: run e2e tests.
- `npm run build:web`: build the dashboard.
- `npm run build`: build dashboard and TypeScript backend.
- `npm test`: run all Vitest tests.
